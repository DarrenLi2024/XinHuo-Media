# 功能模块详解

## 一、首页概览

**路径：** `/`

管理后台首页，提供全局数据概览：

- **统计卡片** — 进行中活动数、待办任务数、嘉宾总数、签到率
- **快捷入口** — 活动管理、智能排座、签到系统、抽奖系统
- **近期活动** — 当前活动的进度与状态一览
- **待办任务** — 高优先级任务快速处理
- **数据趋势** — 近 6 个月活动数据统计（图表待接入）

---

## 二、活动管理

**路径：** `/events`, `/events/new`, `/events/[id]`

活动全生命周期管理：

| 功能 | 说明 |
|------|------|
| 活动列表 | 搜索、筛选、分页；查看活动状态与进度 |
| 创建活动 | 绑定主客户，配置类型、时间、预算、模块开关 |
| 活动详情 | 编辑活动信息，管理赞助商、名单 |
| 活动状态 | draft → pending → preparing → ongoing → completed → archived |

**关联子模块：**

- `/events/[id]/roster` — 活动名单（嘉宾、执行团队、参会人员、赞助商）
- `/events/[id]/sponsors` — 活动赞助商管理
- `/events/tasks` — 任务分工与进度追踪
- `/events/sponsors` — 跨活动赞助商总览

### 活动设置 (EventSettings)

每个活动可独立控制模块开关：

```typescript
{
  require_check_in: boolean;   // 是否需要签到
  allow_lottery: boolean;      // 是否开放抽奖
  enable_seating: boolean;     // 是否启用排座
  enable_script: boolean;      // 是否启用流程台本
  enable_report: boolean;      // 是否生成报告
}
```

## 三、客户主数据

**路径：** `/customers`, `/customers/[id]`

统一管理客户组织与联系人：

- **客户档案** — 组织名称、行业分类、合作意向等级、地区、标签
- **联系人管理** — 多人联系人关联，支持姓名、职位、电话、邮箱、微信等
- **自定义字段** — `custom_fields` 支持灵活扩展
- **合作追踪** — 合作次数、最近合作时间

**客户状态流转：** lead → prospect → active → inactive → archived

---

## 四、供应商管理

**路径：** `/suppliers`

供应商全生命周期管理：

- **供应商分类** — 场地、设备、餐饮、印刷、装潢、摄影、其他
- **联系人信息** — 主联系人、电话、邮箱、地址
- **评价体系** — 综合评分(1-5)、质量/交付/沟通分项评分
- **订单管理** — 物料订单、合同金额、交付进度
- **状态管理** — active / inactive / blacklisted

---

## 五、名单管理 (Roster)

**路径：** `/events/roster`, `/events/[id]/roster`

四大名单面板：

### 执行团队 (Exec Team)
- 姓名、角色、职责描述
- 作为任务分工的人员池

### 嘉宾名单 (Guests)
- 基本信息：姓名、公司、职位
- 嘉宾类型：演讲嘉宾、颁奖嘉宾、主持人、参会者、VIP、工作人员
- 状态追踪：invited → confirmed → checked_in → absent
- 重要性等级：VIP / 重要 / 普通
- 来源标记：手动、导入、客户联系人、报名

### 参会人员 (Attendees)
- 签到状态追踪
- 来源分类（客户推荐、自主报名等）
- 标签管理

### 赞助商名单 (Sponsors)
- 分层级别：冠名、战略、铂金、黄金、银牌、铜牌、支持、自定义
- 合同状态与付款追踪
- 物料需求与广告位管理

---

## 六、任务分工

**路径：** `/events/tasks`

活动任务的拆解与追踪：

- **任务属性** — 名称、描述、负责人、职责、起止日期、交付物
- **优先级** — 高 / 中 / 低
- **依赖关系** — 支持任务间依赖 (`dependencies`)
- **进度追踪** — 0-100% 进度条
- **状态流转** — pending → in_progress → completed（支持 delayed/cancelled）

---

## 七、智能排座

**路径：** `/seating`, `/seating/layout`

拖拽式交互排座系统：

### 核心交互

- **人员池** — 左侧未分配人员列表
- **桌位卡片** — 右侧网格布局，支持拖拽到桌、桌间移动、桌内重排
- **搜索定位** — 搜索已入座人员，自动滚动高亮
- **快速换位** — 一键选中 → 点击目标桌面 → 完成交换

### 桌位管理

- **批量创建** — 设定桌号前缀、数量、容量
- **桌位锁定** — 支持座位锁(seatLock)和位置锁(positionLock)
- **调序** — 拖拽排序或输入目标桌号快速调序

### 工具功能

- **AI 自动排座** — 一键智能分配人员到桌位
- **与平台名单同步** — 从活动名单拉取参会人员
- **导出** — 支持多种格式导出排座结果
- **桌位卡打印** — 生成可打印的桌位卡片

### 场地图编辑 (`/seating/layout`)

Canvas 渲染的场地布局编辑器，支持可视化配置桌椅摆放。

---

## 八、流程台本

**路径：** `/scripts`

活动流程编排与管理：

- **段落编排** — 演讲、表演、视频、颁奖、抽奖、休息、互动等
- **拖拽排序** — 基于 @dnd-kit 的可拖拽排序
- **时间管理** — 每段时长累积计算总时长
- **多格式导出** — Excel、PDF、图片
- **版本管理** — draft / published / archived

---

## 九、表单回收

**路径：** `/forms`, `/forms/submissions`, `/forms/[id]`

在线表单管理：

- **报名表单** — 活动报名收集
- **赞助商报名表单** — 赞助意向收集
- **表单状态** — draft → published → closed
- **提交记录** — 查看、导出表单提交数据
- **公开链接** — 每个表单生成唯一分享链接 `/forms/[id]`

---

## 十、签到系统

**路径：** `/checkin`, `/checkin/entry`, `/checkin/admin`

独立的专业签到模块，自带首页介绍页面：

### 管理后台 (`/checkin/admin`)

- **嘉宾管理** — 手动添加、批量导入（Excel/CSV）、编辑、删除
- **签到操作** — 搜索签到、扫码签到、批量签到
- **实时统计** — 总人数、已签到、未签到、签到率、按类型统计
- **数据导出** — 导出嘉宾名单与签到记录
- **备份恢复** — 云端备份与本地恢复

### 签到入口 (`/checkin/entry`)

- 面向活动现场的简洁签到界面
- 支持扫码和搜索两种签到方式
- 实时反馈签到结果

### 离线能力

- 基于 IndexedDB 的本地数据存储
- 离线可用，在线自动同步到 Supabase

## 十一、大屏抽奖

**路径：** `/lottery`, `/screen`

完整的抽奖系统，支持离线运行：

### 管理后台

| 子模块 | 路径 | 功能 |
|--------|------|------|
| 总览 | `/lottery` | 数据概览、嘉宾导入、奖项进度 |
| 参会人员 | `/lottery/attendees` | 人员编辑、黑名单 |
| 奖项管理 | `/lottery/prizes` | 奖品编辑、排序、排除名单 |
| 锁定中奖 | `/lottery/locked-winners` | 预设中奖、生效时间 |
| 抽奖记录 | `/lottery/draw-records` | 弃奖、补位、导出 |
| 活动信息 | `/lottery/event-info` | 名称、主题、LOGO、页脚 |
| 系统设置 | `/lottery/settings` | 主题、音效、备份 |
| 看板 | `/lottery/dashboard` | 实时抽奖控制台 |

### 抽奖引擎 (`lib/lottery/draw-engine.ts`)

- 随机抽取 / 加权抽取
- 排除已中奖人员
- 支持黑名单与锁定中奖
- 剩余名额计算

### 大屏画面 (`/screen`)

- 炫酷视觉效果（粒子球、碎裂卡片动画）
- Framer Motion 驱动的动画
- 主题可配置：科技蓝 / 金色 / 红金

### 离线架构

- 基于 IndexedDB（`idb`）的离线数据库
- BroadcastChannel 跨标签页实时同步
- 从平台活动一键导入参会人员

## 十二、赞助商管理

**路径：** `/events/sponsors`, `/events/[id]/sponsors`

分层赞助商权益管理：

| 层级 | 说明 |
|------|------|
| title | 冠名赞助 |

| platinum | 铂金 |
| gold | 黄金 |
| silver | 银牌 |
| bronze | 铜牌 |

### 赞助配置

- 赞助类型：现金 / 实物 / 服务 / 媒体 / 混合
- 金额与币种

- 物料需求
- 合同与付款状态追踪

## 十三、复盘报告

**路径：** `/reports`

AI 辅助的活动复盘：

- **数据统计** — 签到率、VIP 出席、任务完成率、预算偏差
- **亮点与问题** — 结构化记录活动亮点与改进点
- **AI 生成** — 基于活动数据自动生成报告文案（`/api/ai/generate-report`）
- **多维度分析** — 赞助商、任务、预算分项统计
- **导出分享** — 支持导出报告

## 模块间关系

```
客户主数据 ────┐
供应商管理 ────┤
              ├──→ 活动管理 ──→ 名单管理 ──→ 智能排座
              │                  │
              │                  ├──→ 任务分工
              │                  ├──→ 流程台本
              │                  ├──→ 签到系统
              │                  ├──→ 抽奖系统
              │                  ├──→ 表单回收
              │                  └──→ 赞助商管理
              │                        │
              └────────────────────────┴──→ 复盘报告
```

- **客户** 和 **供应商** 为主数据模块，独立于具体活动
- **活动** 创建时绑定主客户，后续关联多个客户/供应商
- **名单** 从客户联系人和报名表单汇总
- **签到** 和 **抽奖** 基于活动嘉宾/参会人员名单
- **复盘报告** 汇总活动的全部数据
