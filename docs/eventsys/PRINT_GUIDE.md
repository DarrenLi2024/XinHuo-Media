# 打印启动说明

本文档介绍如何在 EventSync Pro 中使用打印功能生成高质量的 PDF 文档。

## 快速开始

### 方式一：浏览器打印（推荐）

1. 在主页面点击右上角的**设置**按钮（齿轮图标）
2. 在设置面板中找到**导入导出**区域
3. 点击 **PDF** 按钮启动浏览器打印功能
4. 在打印对话框中：
   - 目标打印机选择"另存为 PDF"
   - 纸张大小建议选择 A4
   - 边距建议选择"默认"或"无"
   - 背景图形选项建议勾选
5. 点击保存即可生成 PDF 文件

### 方式二：导出为图片后打印

1. 切换到**导出**视图（点击顶部"导出"标签）
2. 配置导出模板：
   - 上传 LOGO（可选）
   - 填写活动名称和主题
   - 选择皮肤样式
   - 选择要导出的章节/环节
3. 点击**导出 PNG**按钮
4. 生成的图片将自动下载，分辨率 300 DPI，适合高清打印

## 打印质量设置

### 导出图片规格

| 参数 | 数值 | 说明 |
|------|------|------|
| 宽度 | 1206 px | 基于 iPhone 17 Pro 比例 |
| 高度 | 自适应 | 根据内容自动计算 |
| 分辨率 | 300 DPI | 高清打印标准 |
| 格式 | PNG | 无损压缩 |

### 推荐打印尺寸

- **手机浏览**：直接在手机上查看，无需打印
- **宣传册打印**：95mm × 210mm（竖版）
- **海报打印**：按比例放大至 A3 或更大

## 打印注意事项

### 1. 内容准备

- 确保活动信息完整（名称、日期、地点、主办方）
- 检查环节时间是否正确
- 确认各角色职责已填写

### 2. 导出前检查

- 预览导出模板，检查布局
- 确认 LOGO 清晰度
- 检查文字是否有截断

### 3. 纸张选择

- **普通纸**：适合日常办公使用
- **铜版纸**：适合正式场合，效果更好
- **相纸**：适合需要长期保存的版本

### 4. 打印机设置

- 选择最高打印质量
- 关闭"快速打印"选项
- 确保墨水/碳粉充足

## 常见问题

### Q: 打印出来的图片模糊怎么办？

A: 请使用"导出 PNG"功能生成高清图片，分辨率 300 DPI 可确保打印清晰。

### Q: 为什么打印时部分内容被截断？

A: 请在打印设置中调整边距，或选择"适应纸张大小"选项。

### Q: 可以批量打印多个活动的台本吗？

A: 目前需要逐个活动导出打印。建议使用 JSON 导出功能保存活动数据，方便后续管理。

### Q: 如何打印签到记录？

A: 进入签到管理页面（点击顶部"签到"按钮），点击右上角"导出记录"按钮，可导出 CSV 格式的签到记录。
