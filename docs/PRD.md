## 一、产品概述

### 1.1 产品背景

芯火传媒致力于为芯片行业中小微企业提供品牌视觉形象及数字化升级服务。在会务活动领域，芯火传媒已成功举办多场大型活动（如"龙跃芯程 豫商同行"2025春茗盛典、"春茗华章 荣耀绽放"庆功表彰大会等），积累了丰富的活动策划与执行经验。

然而，传统会务管理存在以下痛点：
- **排座效率低**：人工排座耗时耗力，难以兼顾嘉宾关系与座位布局
- **流程协同差**：活动台本修改频繁，多方协作效率低
- **签到体验差**：纸质签到效率低，数据无法实时统计
- **抽奖公平性**：传统抽奖方式缺乏透明度，VIP嘉宾区分困难
- **复盘数据缺失**：活动后缺乏数据支撑，难以量化效果
- **供应商管理混乱**：物料采购分散，成本控制困难
- **任务跟踪困难**：活动筹备涉及多部门，进度难以实时掌控

### 1.2 产品愿景

**打造芯片行业最专业的 AI 智能会务管理平台**，实现：
- 一站式会务全流程管理
- AI 赋能提升效率与质量
- 数据驱动优化决策
- 助力企业品牌价值提升

### 1.3 产品定位

| 维度 | 定位 |
|------|------|
| **目标用户** | 芯片行业企业、行业协会、芯火传媒内部团队 |
| **核心价值** | 降本增效、专业品质、数据驱动、AI赋能 |
| **差异化优势** | 行业深度理解 + AI 智能化 + 全流程覆盖 |
| **商业模式** | SaaS订阅 + 项目定制服务 |

## 二、用户角色与场景

### 2.1 用户角色

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| **超级管理员** | 系统最高权限，负责平台运营 | 系统配置、用户管理、数据看板 |
| **活动负责人** | 活动总策划，负责活动整体统筹 | 活动创建、进度把控、资源协调 |
| **执行人员** | 负责具体任务执行 | 任务接收、状态更新、问题反馈 |
| **现场工作人员** | 活动当天现场执行 | 签到引导、抽奖操作、大屏控制 |
| **供应商** | 物料/设备/服务提供商 | 接收订单、确认报价、交付跟踪 |
| **参会嘉宾** | 活动参与者 | 签到、查看座位、参与互动、查看资料 |

### 2.2 核心业务场景

```
活动筹备期（T-30天 ~ T-1天）
├── 活动创建与基础信息配置
├── 智能排座方案制定
├── 活动流程台本编写与协作
├── 物料供应商对接与采购
├── 任务分工与进度跟踪
└── 嘉宾邀请与信息收集

活动执行期（活动当天）
├── 现场扫码签到
├── 活动大屏互动（抽奖、弹幕等）
├── 流程台本实时执行
└── 现场问题快速响应

活动复盘期（T+1天 ~ T+7天）
├── 签到数据统计分析
├── 活动复盘报告生成
├── 供应商结算与评价
└── 经验沉淀与优化建议
```

### 4.2 智能排座系统 (M02)

#### 4.2.1 核心功能

**功能描述**：利用 AI 技术智能安排活动座位，提高排座效率和合理性。

**功能清单**：

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 场地布局 | 配置场地形状、桌椅布局、舞台位置 | P0 |
| 座位图设计 | 可视化编辑座位布局 | P0 |
| 嘉宾导入 | 批量导入嘉宾信息（Excel/CSV） | P0 |
| 嘉宾分组 | 按部门、职级、关系等维度分组 | P0 |
| AI智能排座 | 根据规则自动排座 | P0 |
| 手动调整 | 拖拽调整座位安排 | P0 |
| VIP专区 | 设置VIP区域和座位 | P1 |
| 座位锁定 | 锁定特定座位禁止调整 | P1 |
| 座位导出 | 导出座位图、嘉宾座位表 | P1 |
| 座位查询 | 嘉宾扫码查询座位 | P1 |
| 座位变更记录 | 记录座位调整历史 | P2 |

**AI排座规则引擎**：

```yaml
排座规则:
  - VIP优先: VIP嘉宾优先安排前排中间位置
  - 同组聚合: 同一团队/部门尽量安排在同一桌
  - 关系避让: 有冲突关系的人避免同桌
  - 职级排序: 职级高的嘉宾安排在更靠前的位置
  - 性别平衡: 每桌男女比例尽量均衡
  - 特殊需求: 残障人士安排靠近通道/出口
  - 随机打散: 在满足以上规则前提下适当随机
```

**数据字段**：

```yaml
场地布局:
  - 场地ID: string
  - 场地名称: string
  - 长度: decimal (米)
  - 宽度: decimal (米)
  - 座位布局类型: enum [剧院式, 课桌式, 圆桌式, U型, 其他]
  - 桌数: integer
  - 每桌座位数: integer
  - 舞台位置: json (坐标和尺寸)
  - 出入口位置: json (坐标列表)

座位实体:
  - 座位ID: string
  - 场地ID: string
  - 座位编号: string (如 A1, B2)
  - 桌号: string
  - 排号: integer
  - 座位类型: enum [普通, VIP, 残障专用, 媒体]
  - 状态: enum [空闲, 已占用, 锁定]
  - 嘉宾ID: string (关联嘉宾)
  - X坐标: decimal
  - Y坐标: decimal

嘉宾实体:
  - 嘉宾ID: string
  - 活动ID: string
  - 姓名: string
  - 手机号: string
  - 公司名称: string
  - 职位: string
  - 职级: enum [高管, 中层, 员工, 其他]
  - VIP等级: integer (0-5)
  - 分组ID: string
  - 特殊需求: text
  - 关系标签: json (关系人列表及关系类型)
  - 座位ID: string
  - 签到状态: boolean
```
