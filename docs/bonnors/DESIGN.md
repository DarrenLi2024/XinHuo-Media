# DESIGN.md - 设计规范文件

> 本文档沉淀项目的视觉、品牌、布局、交互、体验偏好，帮助 AI 工具精准复刻设计。

## 项目与用户画像

### 项目定位
大型活动现场智能抽奖管理系统，面向企业年会、行业峰会等 500-1000 人规模活动。

### 目标用户
- **活动主办方**：需要管理抽奖流程的管理人员
- **现场观众**：参与抽奖的参会嘉宾
- **技术保障人员**：确保系统稳定运行的运维人员

### 使用场景
- 大型会议现场大屏展示
- 实时抽奖互动环节
- 后台管理与数据准备

## 布局与响应式

### 大屏展示页面（/screen）

**布局结构**：
```
┌─────────────────────────────────────────┐
│              顶部活动信息                 │
├─────────────────────────────────────────┤
│                                         │
│         3D地球仪粒子动画区域              │
│         (中央主视觉区)                   │
│                                         │
├──────────────┬──────────────────────────┤
│   奖项侧边栏  │      中奖展示区域         │
│   (左侧固定)  │      (右侧动态)          │
├──────────────┴──────────────────────────┤
│              底部信息栏                   │
└─────────────────────────────────────────┘
```

**尺寸规范**：
- 大屏分辨率：1920x1080（主要适配）
- 粒子区域高度：约 70% 屏幕高度
- 侧边栏宽度：280px
- 中奖卡片：150x200px

## 组件规范

### 中奖卡牌（ShatterCard）

**视觉设计**：
- 卡牌尺寸：150x200px
- 背景：渐变背景 + 玻璃效果
- 边框：金色/主题色边框
- 内容：姓名、公司、桌号
- 动效：悬停发光、碎裂动画

**状态样式**：
| 状态 | 样式 |
|------|------|
| 正常 | 主题色边框 |
| 新中奖 | 发光脉冲效果 |
| 重抽补位 | 金色边框持续发光 |
| 碎裂 | 粒子散开消失 |

### 奖项侧边栏（PrizeSidebar）

**视觉设计**：
- 宽度：280px
- 背景：半透明深色
- 奖项卡片：紧凑排列
- 剩余数量：醒目显示

**交互设计**：
- 点击选择奖项开始抽奖
- 已抽完奖项灰化显示
- 当前奖项高亮边框

### 粒子地球仪（ParticleSphere）

**视觉设计**：
- 粒子数量：500-1000（根据参会人数）
- 粒子颜色：主题色渐变
- 粒子大小：2-4px
- 分布算法：斐波那契球面分布
- 动画：缓慢旋转 + 涌动效果

## 交互与状态

### 抽奖流程动画

**状态流转**：
```
waiting → rolling → winner → (弃奖) → rolling → winner
```

**动画设计**：

| 状态 | 动画效果 |
|------|----------|
| waiting | 粒子缓慢旋转、涌动 |
| rolling | 名字快速滚动、音效播放、粒子加速 |
| winner | 粒子爆炸、烟花特效、卡牌弹出、欢呼音效 |
| 弃奖碎裂 | 卡牌碎裂粒子散开、新卡牌从碎裂位置出现 |

### 音效设计

| 事件 | 音效特点 |
|------|----------|
| 滚动 | 80-120ms间隔、300-600Hz、轻快灵动 |
| 中奖 | 渐进式欢快音调、持续欢呼 |
| 烟花 | 爆炸音效、低频震动 |
| 碎裂 | 玻璃破碎声、快速下降音调 |
| 重抽惊喜 | 强化版中奖音效、持续欢呼 |

## 可访问性与文案

### 文案规范
- 中文优先，简洁明确
- 中奖信息大字号醒目显示
- 系统提示友好清晰

- 色彩对比度满足 WCAG AA 标准

## 素材与实现备注

### 图片资源
- 奖品图片：支持上传或URL导入
- 活动LOGO：支持配置显示
- 默认占位图：主题相关渐变图

### 动画实现
- 粒子效果：纯 Canvas API
- 烟花特效：Canvas 2D
- UI动画：Framer Motion
- 卡牌碎裂：Canvas 粒子 + CSS 动画

### 性能优化
- 粒子使用 requestAnimationFrame
- 音效使用预生成 AudioBuffer
- 图片使用懒加载
- 大列表使用虚拟滚动
