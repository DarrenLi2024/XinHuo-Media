# IC豫商会年度春茗会务管理平台 - 完整资产文档

> **文档版本**: v2.0.0 | **日期**: 2026-06-15 | **项目**: 芯火会务管理系统

---

## 一、系统定位

围绕"客户—活动—名单—赞助—现场执行—复盘报告"的通用型会务管理闭环平台。

核心价值: 以"活动"为主线，客户/关键人/赞助商/嘉宾/参会人/座位/签到/抽奖/台本/供应商/预算/复盘 全部数据统一沉淀，每年复用优化。

---

## 三、核心业务关系

```
客户 → 活动 → 名单 / 赞助商 / 嘉宾 / 签到 / 抽奖 / 排座 / 台本 / 复盘
```

- 一个客户多个活动，一个活动一个主客户
- 所有模块共享同一套活动主体 + 人员主数据
- 人员身份通过标签区分，不复建表

---

## 四、名单管理 (核心资产)

### 统一人员主数据字段

姓名 / 手机号(去重主键) / 微信 / 邮箱 / 公司 / 职务 / 行业 / 城市 / 身份类型(多标签) / 来源渠道 / 报名状态 / 审核状态 / 签到状态 / 签到时间 / 抽奖参与 / 座位安排 / 座位号 / 备注 / 标签 / 所属活动

### 身份类型 (标签化)

普通参会人/商会会员/赞助商代表/论坛嘉宾/演讲嘉宾/特邀嘉宾/主办方人员/协办方人员/媒体人员/工作人员/供应商人员/VIP/领导嘉宾

### 去重规则

1. 手机号一致 → 同一人
2. 姓名+公司一致 → 疑似重复
3. 姓名同公司不同 → 人工确认
4. 微信/邮箱一致 → 疑似重复

## 五、表单回收模块

- 报名表单提交 → 校验 → 去重 → 活动参会名单
- 赞助商表单提交 → 校验 → 去重 → 赞助商模块 + 同步人员名单

## 七、抽奖名单模块

字段: 名称/类型/联系人/电话/微信/报价/合同金额/服务内容/评价/付款/发票/历史记录

---

## 十、AI建设原则

1. 活动是核心对象 2. 客户是创建主体 3. 名单是核心资产
4. 人员统一主数据 5. 标签区分身份 6. 表单自动写入名单
7. 各模块互通 8. 统一数据源 9. 支持增删改查批导入导出
10. 多客户多活动多角色权限架构

---

## 十一、MVP三阶段

**Phase 1 (基础可用)**: 客户/活动/名单/嘉宾/赞助商/报名表/赞助表/导入导出/签到/抽奖
**Phase 2 (现场执行)**: 智能排座/流程台本/签到大屏/抽奖大屏/嘉宾接待/赞助权益
**Phase 3 (智能复盘)**: 复盘报告/赞助回报/客户交付/AI宣传稿/历史沉淀/供应商评价/预算费用
